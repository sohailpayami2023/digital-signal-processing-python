# Digital Signal Processing & Wireless Communications in Python

This repository is a practical playground for learning Digital Signal Processing (DSP) and wireless communication concepts through Python implementation. The goal is to move from basic signal theory to complex systems like **OFDM (Orthogonal Frequency Division Multiplexing)** and **MIMO (Multiple-Input Multiple-Output)**.

---

## 🚧 Project Status: Learning
*Currently focusing on the fundamentals of signal manipulation and noise modeling in Python.*

## 🎯 Objectives
The objective of this project is to develop a deep, hands-on understanding of how digital information is transformed into physical waves and transmitted across a simulated wireless channel using Python libraries.

## 📂 Project Roadmap
- [] **Module 1: Signal Fundamentals**
    - [ ] Sine wave generation ($A, f, \phi$)
    - [ ] Simulating AWGN (Additive White Gaussian Noise)
    - [ ] Signal visualization with Matplotlib
- [ ] **Module 2: Filter Design**
    - [ ] Low-pass, High-pass, and Band-pass Butterworth filters
    - [ ] Spectral analysis using FFT (Fast Fourier Transform)
- [ ] **Module 3: Digital Modulation**
    - [ ] Constellation mapping (BPSK, QPSK, QAM)
    - [ ] Pulse shaping (Root-Raised Cosine)
- [ ] **Module 4: OFDM Implementation**
    - [ ] IFFT/FFT block processing
    - [ ] Cyclic Prefix (CP) insertion to combat ISI
    - [ ] Pilot-based channel estimation
- [ ] **Module 5: MIMO & Advanced Topics**
    - [ ] Spatial Multiplexing and Diversity
    - [ ] Beamforming basics
    - [ ] Bit Error Rate (BER) analysis for MIMO systems

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Core Libraries:** 
  - `NumPy`: For numerical operations and matrix math
  - `SciPy`: For the signal processing toolbox and filtering
  - `Matplotlib`: For data and waveform visualization

## 🚀 How to use this Repo
Most scripts are designed for **Google Colab**. You can open the notebooks directly from the repository to experiment with parameters in real-time.
